# 优惠券中心 需求说明 v0.3

## 1. 券类型
系统支持三种优惠券：满减券、折扣券、无门槛券。

- 满减券：订单金额达到门槛后立减固定金额，例如满 100 减 20。
- 折扣券：按折扣率减免，单笔订单最高减 50 元。
- 无门槛券：无使用门槛，直接抵扣。

## 2. 领取规则
- 每个用户每种券限领 1 张。
- 券库存为 0 时，领取按钮置灰并提示"已领完"。
- 领取成功后券立即进入用户券包。

## 3. 有效期
自领取时刻起 7 天内有效，过期后不可使用，券包中展示为"已过期"。

## 4. 使用规则
- 同一订单只能使用一张券，不可叠加。
- 订单金额低于满减门槛时，该券不可选。
- 使用折扣券后订单实付金额不得低于 0.01 元。

## 5. 退款
订单退款成功后，已使用的券退回用户券包，有效期不变。

## 6. 管理后台
- 运营角色可创建券、设置库存上限、查看领取记录。
- 超级管理员可调整任意券的库存，并可下架券。
- 下架后用户不可再领取，已领取的券仍可正常使用。
