## Overview

系统采用三层数据流架构，核心数据落在三张基础表：学生信息表（student_info）、学生档案表（student_file）、系统操作日志表（system_log）。档案与学生通过学号绑定，日志独立存储且永久留存。所有数据的录入、存储、展示与导出执行统一的格式标准，包括日期时间、学号、身份证、手机号、档案编号、状态枚举与附件规范。

## 数据流架构

系统采用「前端页面 → 后端服务校验处理 → 数据库/文件服务器存储」三层数据流架构。

- 所有数据提交必须经过后端校验、过滤、格式化。
- 前端仅负责数据展示与表单提交，无直接数据库操作权限。

### 学生信息数据流

| 场景 | 链路 |
|------|------|
| 新增/编辑 | 前端表单提交 → 后端格式校验、唯一性校验、空值校验 → 数据标准化格式化 → 写入/更新学生信息数据表 → 返回结果至前端 |
| 查询/导出 | 前端提交筛选参数 → 后端条件查询 → 排序、格式化 → 前端渲染列表或生成导出文件 |
| 删除 | 前端发起删除 → 后端校验权限、校验关联档案状态 → 合法则删除 → 写入操作日志 |

### 学生档案数据流

| 场景 | 链路 |
|------|------|
| 新增 | 前端提交文字数据 + 附件文件 → 后端校验数据完整性、附件格式及大小 → 附件上传至文件服务器、文字数据存入档案表 → 通过学号绑定学生关联关系 |
| 归档 | 前端发起归档 → 后端校验当前状态与数据完整性 → 更新归档状态与归档时间 → 锁定数据、生成归档日志 |
| 查询 | 通过学生 ID、学号、档案编号双向关联查询，联动返回学生基础信息与对应档案数据 |

### 数据联动规则

- 学生信息与档案数据强关联，通过学生唯一 ID、学号双向绑定；删除学生信息自动同步清理该学生所有未归档临时档案。
- 已归档档案数据禁止覆盖修改，仅可通过日志记录操作行为。
- 系统操作日志独立存储、永久留存，不随业务数据删除而清空。

## 学生信息表（student_info）

| 字段名 | 说明 | 类型 | 必填 | 约束 |
|--------|------|------|------|------|
| student_id | 学生唯一 ID | bigint | 是 | 主键、自增、全局唯一 |
| student_no | 学号 | varchar(20) | 是 | 全局唯一、不可重复、新增后不可修改 |
| student_name | 学生姓名 | varchar(30) | 是 | 非空，支持中文、英文 |
| gender | 性别 | varchar(10) | 是 | 仅允许枚举值：男、女 |
| birth_date | 出生日期 | date | 是 | 合法日期格式，不能为空 |
| grade | 年级 | varchar(20) | 是 | 格式示例：2022级、2023级 |
| class_name | 班级 | varchar(30) | 是 | 非空，填写完整班级名称 |
| id_card | 身份证号 | varchar(18) | 是 | 18 位合法身份证、全局唯一、不可修改 |
| phone | 联系电话 | varchar(11) | 是 | 11 位合法手机号，纯数字 |
| status | 学籍状态 | varchar(20) | 是 | 枚举值：在读、休学、退学、毕业 |
| create_time | 创建时间 | datetime | 是 | 系统自动生成，不可手动修改 |
| update_time | 更新时间 | datetime | 是 | 数据修改时自动更新 |

## 学生档案表（student_file）

| 字段名 | 说明 | 类型 | 必填 | 约束 |
|--------|------|------|------|------|
| file_id | 档案唯一 ID | bigint | 是 | 主键、自增、唯一 |
| file_no | 档案编号 | varchar(30) | 是 | 系统自动生成、全局唯一、不可修改 |
| student_no | 关联学号 | varchar(20) | 是 | 关联学生信息表学号，建立绑定关系 |
| file_type | 档案类型 | varchar(20) | 是 | 枚举值：学籍档案、奖惩档案、变动档案、毕业档案 |
| file_summary | 档案摘要 | varchar(500) | 是 | 简要概括档案核心内容，不能为空 |
| file_content | 档案详细内容 | text | 是 | 完整记录档案正文信息 |
| file_url | 附件地址 | varchar(255) | 否 | 存储文件服务器路径，无附件则为空 |
| archive_status | 归档状态 | varchar(10) | 是 | 枚举值：未归档、已归档，默认未归档 |
| create_user | 创建人 | varchar(30) | 是 | 记录系统登录账号 |
| archive_time | 归档时间 | datetime | 否 | 归档操作后系统自动生成 |
| create_time | 创建时间 | datetime | 是 | 系统自动生成，不可修改 |

## 操作日志表（system_log）

| 字段名 | 说明 | 类型 | 必填 | 约束 |
|--------|------|------|------|------|
| log_id | 日志 ID | bigint | 是 | 主键、自增、唯一 |
| oper_user | 操作人 | varchar(30) | 是 | 记录操作人员登录账号 |
| oper_type | 操作类型 | varchar(20) | 是 | 枚举值：新增、编辑、删除、归档、导出、查询 |
| oper_content | 操作内容 | varchar(500) | 是 | 精准记录操作对象、操作行为详情 |
| oper_ip | 操作 IP | varchar(50) | 是 | 记录客户端访问 IP，用于溯源 |
| oper_time | 操作时间 | datetime | 是 | 系统自动生成操作时间 |

## 统一数据格式规范

所有数据在录入、存储、页面展示、文件导出环节执行同一套格式标准。

### 基础数据格式

| 数据项 | 规范 | 示例 |
|--------|------|------|
| 日期 | YYYY-MM-DD | 2025-09-27 |
| 时间 | YYYY-MM-DD HH:mm:ss | 2025-09-27 15:30:00 |
| 学号 | 固定 10 位纯数字，院校统一编码，全局唯一 | — |
| 身份证 | 严格 18 位字符，末尾小写 x 自动统一转换为大写 X | — |
| 手机号 | 严格 11 位纯数字，无空格、无符号、无特殊字符 | — |

### 档案编号格式

档案编号由系统全自动生成，人工不可干预，格式为 `DA-四位年份-两位月份-四位当日流水号`，示例：`DA-20250927-0001`，全局唯一不重复。

### 状态数据格式

- 学籍状态：仅支持固定枚举值「在读、休学、退学、毕业」，无自定义输入。
- 档案状态：仅支持固定枚举值「未归档、已归档」，无自定义输入。
- 所有状态字段均为下拉选择，杜绝非标状态数据。

### 附件格式规范

| 项目 | 规范 |
|------|------|
| 支持格式 | JPG、PNG、PDF、Word、Excel |
| 单文件大小上限 | 最大 20MB |
| 命名规则 | 自动重命名为「档案编号_原文件名」，避免文件重名覆盖 |
