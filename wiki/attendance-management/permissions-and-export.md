# 分级管理权限与打卡数据导出

> Sources: 企业微信帮助文档《打卡管理》, Unknown
> Raw: [企业微信帮助文档《打卡管理》](../../raw/attendance-management/wecom-attendance-management.md)
> Updated: 2026-10-19

## Overview

打卡的管理侧收敛为两件事：谁能改规则，以及记录怎么取出来。企业微信把管理员分成超级管理员与分级管理员两类，权限按「全员」与「管辖范围」划界；打卡记录则提供管理后台的筛选与 Excel 导出、以及面向开发者的 API 导出两条通道。

## 两类管理员

| 类型 | 设置规则的范围 | 查看统计的范围 |
|------|----------------|----------------|
| 超级管理员 | 可在管理后台和移动端给公司全员设置打卡规则 | 全员打卡统计 |
| 分级管理员 | 只能设置和修改管辖范围内员工的打卡规则 | 管辖范围内员工的打卡统计 |

超级管理员还承担权限分配职责：可对所有管理员的权限进行分配，保证各司其职。

管理员配置入口：【管理后台】>【我的企业】>【权限管理】>【添加系统管理员】>【设置管理员信息】。

## 查看与导出打卡记录

入口：【管理后台】>【企业应用】>【打卡】>【上下班打卡】>【查看】。

- 导出：在「按日统计」和「按月统计」Tab 右上角导出 Excel 打卡数据。
- 筛选：顶部工具栏可按时间、部门、打卡人员、打卡状态筛选打卡记录。

## API 导出数据

有开发能力的企业可深度定制打卡功能。企业微信提供 API 接口，管理员可通过接口调用导出打卡数据，并结合企业的假期管理、工资结算系统高效输出薪酬报表。

这条路径与后台 Excel 导出是并列通道，面向的是系统间集成而非人工核对。

## 可测试的关键判定点

- 分级管理员只能操作管辖范围内的规则与统计，范围外的部门/员工必须不可见或不可操作。
- 超级管理员的规则设置需在管理后台与移动端两侧均可生效。
- 按日统计与按月统计两份导出数据，须分别与对应 Tab 及筛选条件一致。
- 筛选条件（时间、部门、打卡人员、打卡状态）组合使用时结果应取交集。
- API 导出数据应与后台导出在相同时间范围下口径一致。
- 新增的分级管理员未分配管辖范围时，不应具备任何规则修改权限（边界场景，需按实际产品行为确认）。
